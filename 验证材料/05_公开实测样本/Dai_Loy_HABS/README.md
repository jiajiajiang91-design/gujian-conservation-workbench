# Dai Loy HABS 小体量公开实测样本

## 1. 用途

本目录用于验证“资料输入—结构化建模—三维模型—平立剖制图—CAD 检查—成果交付”的工程流程。

样本来自美国历史建筑调查 HABS CA-2071 的 Dai Loy Gambling Museum。建筑记录于 1979 年完成，包含现场照片、建筑说明、两层平面、立面和两个剖面。目录内 6 个文件合计 1,354,283 字节，不含航拍、视频或大体量点云。

该建筑是美国华人木构建筑，不是中国官式古建。本样本只能验证资料管理、几何建模和专业制图流程，不能证明系统已经理解中国古代木构。

## 2. 已核验事实

- HABS 调查号为 `CA-2071 W`。
- 建筑建于 1916 年，调查时用作博物馆。
- 建筑为一层半木框架，三开间正面约 24 英尺宽，进深约 60 英尺。
- 主体为双坡屋顶，门廊为单坡屋顶，屋面覆盖压型金属板。
- 图纸 16 包含首层和二层平面，图纸 17 包含 A-A 剖面与西立面，图纸 18 包含 B-B 剖面。
- 图纸标注比例为 `1:48`，同时提供图示比例尺。

这些事实来自建筑说明和 HABS 图纸，不应标成系统现场实测。系统导入时必须保留原资料来源、调查时间和调查机构。

## 4. 两种验证方式

### 4.1 工程复现

将 6 个文件全部作为输入，验证以下事项：

1. 每条尺寸和构造事实可以回到原图纸或说明页。
2. 三维模型与首层、二层、立面和剖面使用同一组建筑对象和尺寸。
3. DXF 中的图层、线型、线宽、文字、尺寸、剖切、图签和打印设置符合项目制图标准。
4. 图纸变化由模型和项目数据驱动，不通过页面坐标或项目编号硬编码。
5. 输出包含可编辑 CAD、三维交换文件、预览、检查报告、结构化项目数据和来源记录。

该方式验证工程实现和文件质量，不用于证明系统可以从一张照片自动恢复全部实测尺寸。

### 4.2 未知信息盲测

输入 `01`、`02`、`03` 和 `06`，暂不向系统提供 `04`、`05`。系统应：

1. 建立平面、空间和已知构造关系。
2. 把没有直接证据的高度、坡度和不可见构造保留为未知或候选。
3. 生成可审核的参考模型，不把候选标成现场实测。
4. 完成后再用 `04`、`05` 对照结果，区分正确推断、可接受候选和无依据内容。

该方式验证事实边界和不确定性处理。缺失数据不能靠默认值补成正式结果。

## 5. 通过条件

- 导入文件的哈希与清单一致。
- 照片、文字、尺寸、建筑对象、模型和成果之间可以双向追溯。
- 已知尺寸保持原单位，并可无损换算到项目单位。
- 平面、立面、剖面和三维模型没有相互矛盾的对象关系。
- 未知尺寸不被演示值、模型推测或规则默认值替代。
- CAD 文件可编辑、可检查、可打印，在两种常用 CAD 软件中打开后没有致命错误。
- 代理测试成果明确标为代理成果，不冒充 HABS 原图或正式签发成果。

数值容差、制图模板和 CAD 软件清单需要在 PRD 确认后的技术架构中确定。
