# 图纸表达差距清单（阶段 C1）

建立日期：2026-08-16。分支 `codex/professional-workbench-rebuild`。对照对象为两份外部参考 DWG 的只读审查记录与 `08_专业制图与建模质量基准.md` 第 4 章最低要求。

## 一、结论

当前图纸的几何求交与图种覆盖已达成套要求，差距集中在标注体系：每个视图固定产出 3 条标注（1 条总宽尺寸、1 条图名、1 条资格声明），与建筑规模无关。HABS 样本 712 条结构线与第三项目 101,977 条结构线产生的标注数量完全相同，均为 21 项。这说明标注不是按构件或按尺寸链生成的体系，而是每视图固定模板。

四个对照维度中，图种闭合与版面组织基本达标，标注密度与构造层级存在结构性缺口。是否投入补齐由 JIAJIA 决策，本清单只提供量化事实与工作量估计。

## 三、四维度差距

### 3.1 图种：已达标

两个项目均产出 7 个视图，覆盖平面、屋顶平面、立面、横剖、纵剖、详图，第三项目另有轴测。详图比例（1:12 与 1:20）高于总图比例（1:50 与 1:75），符合基准 4.1 关于详图比例的要求。

未覆盖的图种为基准 4.1 列出的门窗表、材料表、病害表与图纸目录。这四项是表格类成果，不依赖几何求交能力，属独立工作项。

### 3.2 标注密度：主要差距

当前每视图固定 3 条标注，构成为视图整体宽度的一条水平线性尺寸（`dxf_writer.py:124`）、图名与比例文字、资格声明多行文字。基准 4.2 要求的以下内容全部缺失：

| 基准 4.2 要求 | 当前状态 | 影响 |
|---|---|---|
| 定位轴线与轴号 | 无。`GJ-AXIS` 图层为空 | 无法按轴线复核开间进深 |
| 开间、进深、构件定位尺寸 | 无，仅 1 条总宽 | 尺寸链不可复核 |
| 室内外、檐口、屋脊、台基标高 | 无 | 竖向关系不可复核 |
| 剖切符号、索引符号、详图符号 | 无 | 详图与总图无索引对应，违反基准 4.3 的追溯要求 |
| 北向符号 | 无 | 平面朝向不可判断 |
| 构件名称、规格、做法说明 | 无 | 构件语义不在图面呈现 |

形制参数层（R4，提交 281dd70）已能派生带出处与容差的应然尺寸，词表层（R3，提交 201eff3）已有 27 类构件的首选名与别名。这两层是标注内容的现成数据来源，标注体系缺的是从这些数据到图面标注对象的生成环节。此为事实推断，验证方式为实现一条轴网尺寸链后检查其值是否可直接取自 ArchetypeSpec 与 FactEnvelope。

### 3.3 构造层级：部分差距

剖切与轮廓分层已实现且分层正确（剖切线独立于 `GJ-CUT`，轮廓在 `GJ-OUTLINE`），材料填充按区域生成。基准 4.2 要求的六类线（可见、剖切、投影、隐藏、中心、辅助）中，投影线与隐藏线在两个项目产物中均为 0 条。

几何表达上，模型空间全部为直线段，无 ARC、SPLINE、CIRCLE、LWPOLYLINE。屋面坡曲与檐口曲线以短直线离散呈现，这是第三项目 93,638 条轮廓线的主要来源。参考 DWG 使用 1,684 条弧与 900 条样条表达同类曲线。当前做法在打印外观上可接受，但文件体积（45.9 MB）与编辑友好度差于弧线表达。是否需要弧线拟合取决于成果用途，属可选项。

### 3.4 版面组织：基本达标

两个项目均为 2 张图纸、9 个视口，图纸空间含图框多段线、图签块引用（`GJ_TITLEBLOCK`，含项目、图名、图号、状态、修订、日期六个属性）与说明文字。基准 4.2 要求的图名、图号、比例、图幅、图签、修订与打印设置均已具备。

参考 DWG 自身在这一维度反而不达标：其 125,060 个对象全部位于模型空间，两个图纸空间布局为空，没有用视口组织成套图纸（见 `外部参考_一套完整的古建施工图_只读审查.md` 第 2.1 节）。本项目在版面组织上不需要向参考文件看齐。

## 四、补齐方案与工作量估计

以下为待决策项，未实施。工作量按提交单元估计，不含浏览器验证与证据整理。

| 方案 | 内容 | 估计 | 依赖 |
|---|---|---|---|
| A 轴网与尺寸链 | 从 ArchetypeSpec 的柱网与逐间尺寸生成轴线、轴号、开间进深尺寸与总尺寸三级链 | 1 至 2 个提交 | R4 已就绪 |
| B 标高与剖切索引 | 竖向标高标记、剖切符号、详图索引符号与详图回引 | 1 至 2 个提交 | 需定义符号块 |
| C 构件标注 | 按词表首选名对关键构件出引线标注 | 1 个提交 | R3 已就绪；需解决标注避让 |
| D 表格类成果 | 门窗表、材料表、图纸目录 | 1 至 2 个提交 | 独立于几何 |
| E 曲线拟合 | 屋面与檐口曲线由直线段拟合为弧或样条 | 1 个提交，风险较高 | 需重做求交输出与验证器 |

方案 A 至 C 直接回应基准 4.2 与 4.3 的追溯要求，是差距的主体。方案 D 独立且风险低。方案 E 属表达优化，不影响专业可复核性，建议缓做。
