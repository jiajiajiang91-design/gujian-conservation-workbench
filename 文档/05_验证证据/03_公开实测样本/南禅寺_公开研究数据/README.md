# 南禅寺大殿公开研究数据

本目录保存南禅寺大殿的结构化研究数据，用于验证中国古代木构的来源关系、数值约束和局部多视图流程。它不是正式测绘项目包。

## 样本内容

- `source-measurements.json`：转录论文表 3 至表 6、表 9、表 10、表 12 和表 13 的测量值，并单独记录论文作者的理想复原尺寸。

照片作者为 Patrick20242023，许可为 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)。每张照片的来源页面、归属文本、是否修改、文件哈希和大小写入 `source-measurements.json`。

## 测量来源

张荣、王一臻、王麒、李玉敏：《南禅寺大殿重建背景、材分营造制度分析及建筑像设空间布局研究》，《建筑史学刊》2022 年第 2 期。

DOI：`10.12329/20969368.2022.02001`。

研究使用三维点云和手工测量。论文报告的点云密度为 2 mm，单点精度为 0.3 mm，整体误差不大于 3 mm；重要铺作构件使用游标卡尺测量，精度为 0.1 mm。

论文 PDF 受版权保护，不放入仓库。结构化数据为事实转录，每组数据保留 PDF 页码、印刷页码和表号。论文中的剖面、立面和复原图也不复制。

## 数据分层

`source-measurements.json` 把数据分成四类：

1. `scanMeasured`：论文公布的点云或手工测量值。
2. `statisticalDerived`：测量样本的均值、标准差和材分候选。每项使用英文具名字段，并保存表号和计算输入关系。
3. `authorReconstruction`：论文作者根据实测和营造制度选择的材分、营造尺与理想设计尺寸。
4. `photoObserved`：许可照片中可以直接观察的形制。

旧 PoC JSON 中的台基、门窗、屋脊和檐口估算值没有进入本样本。人工确认也不能把作者复原值改成现场实测值。

论文表 10 的栌斗深度存在内部冲突。16 个列出值的直接均值为 438.1313 mm，论文公布均值为 432.65 mm。文中没有说明排除项。

本样本保留两者并标为冲突，不自动选取真值。

## 验证方式

### 局部工程复建

输入三张照片、`scanMeasured`、`statisticalDerived` 和 `authorReconstruction`。

系统生成带未知项的局部研究模型，以及柱网、柱高、屋架和铺作相关的试验平面、立面、剖面与 CAD。系统逐项比较实测值、统计值和论文作者的理想复原值，不把作者选择改成现场实测。

### 未知量测试

只输入照片、`scanMeasured` 和 `statisticalDerived`，隐藏 `authorReconstruction`。系统只建立证据支持的局部骨架，保留不可见构造和缺失尺寸，不得使用旧 PoC 估算值。

完成后再用作者复原尺寸评估误差。

## 适用边界

本样本适合验证资料和冲突导入、柱网、柱高、柱截面、部分屋架与铺作尺寸、局部多视图一致性，以及实测与作者复原的分层比较。

它缺少原始点云、现场记录、完整构件拓扑、完整梁架与节点尺寸、屋面曲线和九脊关系、台基与门窗尺寸、侧后立面照片、内部空间资料、完整权属声明和本项目责任测绘人员。

因此，本样本不能证明完整建筑建模或事务所级 CAD，也不能用于正式签发。系统只能生成带未知状态的局部研究模型和试验图，不得补成确定事实。
