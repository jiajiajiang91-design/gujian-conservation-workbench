# 里程碑二最小数据字典

| 对象 | 含义与唯一责任 | 来源 | 缺失影响 |
|---|---|---|---|
| `TypedParameter` | 区分长度、角度、计数、比例和文本；计数不得使用 mm | human / rule / demo / measured | 参数语义不明时不得进入 GeometrySpec |
| `UnknownValue` | 保存原因码、所需证据、影响对象和代理/正式资格阻断 | human / rule / system metadata | 未知项不能用默认值或 demo 值补齐 |
| `GeometrySpec` | 当前项目版本的坐标系、对象、稳定 ID、类型化参数、接口和证据引用 | 项目事实与人工决定 | 无可靠几何时阻断完整模型与完整图纸 |
| `CadJobInputSnapshot` | 固定作业输入版本、哈希、允许的资源与大小 | system metadata | worker 不得接收 URL、用户路径、外部 DWG 或任意提示 |
| `GeometryRevision` | 同一次生成的实体闭包、接口闭包、IFC、GLB、manifest、报告、预览和来源映射 | CAD worker，经命令提交 | 任一闭包不一致时全部成果失效 |
| `ArtifactRequirementMatrix` | 当前任务指定的图种、图幅、比例、布局、标题、日期和交付范围 | task + human decision | 不得退回固定十视图、两张 A1 或固定日期 |
| `ViewGeometry` | 从同一 GeometryRevision 求交或投影得到的二维几何 | CAD worker | 禁止独立补画结构线 |
| `DrawingIR` | ViewGeometry、标注、材料区和布局的单一跨格式读模型 | CAD worker | DXF/SVG/PDF 必须读取同一 IR |
| `ArtifactRecord` | 成果资源、哈希、来源、GeometryRevision 和资格阻断 | system metadata | 跨版本成果不能混入当前交付 |
| `CheckRun` | 记录机器检查与诚实阻断，不授予专业资格 | rule / system metadata | 未检查成果不得进入代理交付草案 |
| `DeliveryEvaluation` | 判断代理成果可建立或必须阻断 | rule + current records | 高都缺事实时必须是 `blocked` |
| `DeliveryDraft` | 未签发代理交付草案及其 manifest | human intention through command | 始终 `L1=false`、unsigned、不可正式使用 |

来源类型严格分开：`model` 只产生候选，`rule` 产生规则结果，`human` 记录人工决定，`demo` 记录团队演示输入，`system` 只用于审计与元数据。
