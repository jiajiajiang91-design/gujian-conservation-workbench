# PM 场景参考索引

产品经理先判断任务场景，再读取一个对应文件。不要一次加载全部参考文件。

| 任务场景 | 参考文件 |
|---|---|
| 新方向、新品类、是否立项 | `.claude/references/pm/立项与新品类.md` |
| 用户分层、动作、场景、旅程 | `.claude/references/pm/用户与场景.md` |
| MVP、版本范围、优先级、路线图 | `.claude/references/pm/MVP与优先级.md` |
| 模型成本、定价、投入产出 | `.claude/references/pm/商业与模型成本.md` |
| PRD、MRD、立项书和分析文件审阅 | `.claude/references/pm/文档审阅.md` |

混合任务按依赖顺序逐个读取。例如，新方向先做立项判断，确认后再做用户场景和 MVP，不同时套用全部方法。
