# 古建保护成果工作台

面向古建保护成果整理、核对、生成、交付和持续更新的本地优先工作台。本仓库中的代理成果用于验证流程，不代表正式测绘成果或专业签发。

## 运行

环境要求：Node.js 20.19 或更高版本。

```powershell
npm install
npm run dev
```

浏览器访问 `http://127.0.0.1:5173/`。开发模式同时启动 Vite 和独立 Node 服务；项目内容只保存在浏览器的 `gujian-workbench-v2` IndexedDB 中，Node 服务不默认保存项目。

生产构建与本地发布：

```powershell
npm run build
npm start
```

浏览器访问 `http://127.0.0.1:8795/`。Node 服务只发布 `dist` 中的新工作台和 `/api`，不再发布旧页面、旧脚本或旧数据入口。

## 核心能力

- 新建项目，或导入、导出 `project.json` 与 `.gujian.zip` 项目包。
- 对 ZIP 路径、文件数量、大小、MIME、schema、资源哈希和远程资源进行校验。
- 用受控业务命令记录项目版本、模型运行、规则运行、人工决定、成果和审计事件。
- 区分 `model`、`rule`、`human` 与 `demo` 来源；系统事件不作为业务事实来源。
- 生成真实 SVG、DXF、检查报告、交付清单和代理交付 ZIP。
- 在资料、对象、来源、人工核对和成果版本之间查看关系。

## 演示项目

- 高都：使用独立且自洽的 demo 制图输入，完成代理 SVG、DXF、检查报告和交付包。原项目中的尺寸矛盾保持原样，不作为代理制图输入。
- 东呈：验证五开间对象、资料缺失和阻断路径。系统只生成无实测尺寸的证据草图和不足报告，不生成尺寸立面或代理交付包。

两套样例数据位于 `data/v2/`，不嵌入页面组件或业务服务。演示数据不会标为真实模型结果，也不能进入正式成果。

## 数据和责任边界

- 业务快照、运行记录、成果、交付、资源与审计分别持久化，快照不递归保存历史版本。
- 测量记录必须包含测量人、时间、方法、单位和原始证据。模型转写仍是候选，不会变成现场实测。
- 正式资格由当前事实重新计算，不写入来源记录。
- 本轮未实现组织权限、真实身份、DWG 和法定签发，因此正式签发始终锁定。

## 验证

```powershell
npm run check
npm test
npm run test:e2e
npm run build
```

- `check`：旧代码语法特征检查和新应用类型检查。
- `test`：旧行为回归测试与领域、项目包、命令、成果和交付单元测试。
- `test:e2e`：高都正常代理交付、东呈阻断、1280/1440 桌面宽度。
