# MRD 模板（市场需求文档）

> 适用场景：新产品概念验证、新市场进入决策、为 PRD 提供市场输入。本模板面向决策层和产品团队，回答"这个市场值不值得做、靠什么赚钱"。
>
> MRD 的出发点是商业角度：佐证产品能不能赚钱，而不是能不能实现功能。详略分配：用户洞察写细一些，竞品写基本格局即可，需求只做粗定义（细节归 PRD），商业落地方式是最重要的一节。
