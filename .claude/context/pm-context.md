## 二、产品定位

> 面向古建测绘与保护项目团队，把照片、测量记录、历史图纸和任务要求转成可追溯的建筑数据、三维模型和专业图纸，经专业复核形成可交付、可归档、可持续更新的成果。

产品名称为“古建保护成果工作台”。产品形态是正式 toB 工作台，不是单项目演示页或后台管理系统。

核心 PRD 描述终局产品；技术架构定义目标状态、迁移路径和实施门槛。旧工作台、v2 图纸试验和 v3 几何试验只作为迁移资产与证据，不代表目标系统已经完成。

## 三、当前产品决策

1. 成果目录、比例、图幅、图纸要求、CAD 资格工具、项目制图标准和交付范围以 R001 的任务要求为唯一业务来源。
2. 三维、平面、立面、剖面、详图、IFC、GLB、DXF、SVG、PDF、报告和预览必须引用同一 `GeometryRevision`。
3. 项目事实、模型候选、规则结果、人工决定和演示数据分别记录；系统行为只进入审计。
4. AI 先处理资料理解、分类、转写、候选和问题分析。规则、几何、制图、资格和交付门槛由确定性程序执行。
5. 人工只承担三类责任：补充缺失现场事实；选择没有唯一答案的专业方案；审核成组成果并承担签发责任。
6. 同一责任人同时具备审核与签发权限时，一次接受操作同时完成审核与成果批准签名。只有组织要求职责分离时，才由第二人执行签发。
7. 当前模型适配使用 Kimi K2.6，官方模型标识为 `kimi-k2.6`。领域契约保持供应商中立。密钥、官方地址、任务注册表和预算只保存在 Node 服务。
8. 本地模式以 IndexedDB v3 为项目真源；私有部署以 PostgreSQL 和对象存储为项目真源。同一部署只允许一个命令权威。
9. 本地模式不开放正式签发，只允许代理交付。私有部署接入真实身份、权限和签名后，才可验证正式发布。

## 四、CAD 与三维质量边界

- 规范 CAD 当前使用 AutoCAD 2024 或 Core Console 完成打开、`AUDIT`、编辑、保存、重开和打印检查。
- QCAD 3.32.9 只用于打开、查看、选择和打印兼容检查。其保存副本会改写原生尺寸和视口锁定，不得覆盖规范 DXF，也不得作为资格证据。
- `13-12_专业制图与建模质量基准.md` v0.4 采用“规范资格工具 + 第二兼容工具”规则。此前要求第二工具无损编辑保存的条款已被 PRD v1.1 和技术架构 v1.2 取代。
- 外部 DWG 和参考图只用于人工比较图种、表达深度和版面组织；不得进入项目事实、生成输入、样例项目包或交付包。
- 生成器和验证器不能共享关键判断实现。技术验证器不得自行授予 L1、L2 或正式资格。

3. 通用几何与 CAD 内核能否跨不同形制、成果目录和版式工作。

6. 项目资料的权属、保密和模型传输是否允许真实使用。
7. 真实项目是否产生继续使用、询价、采购测试或付费行为。
