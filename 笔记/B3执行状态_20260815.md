## 性能与调度（2026-08-15 补充）

- 第三项目成组图纸生成为长时计算（1258 实体七视图 HLR，单线程，数小时级），已记 P1：按视图并行化。
- Windows 11 会对后台应用进程树启用能效节流（EcoQoS），worker 作为应用子进程在用户不交互时被压到近停。处置：用 SetProcessInformation(ProcessPowerThrottling) 豁免 python 与 node 进程（本轮已验证豁免后静默满速）。后续应在 server 派生 worker 时默认豁免。

## 环境注意事项

- 页面必须用 `http://127.0.0.1:5173`（IndexedDB 按源隔离，localhost 是另一个库）。
- 面板隐藏时"清空本地库"的 confirm() 会被浏览器面板拦截返回 false，等于没点；脚本中改用 indexedDB.deleteDatabase。
- 第三项目包静态服务：`workers/cad/.venv/Scripts/python.exe` 跑 scratchpad 的 serve_cors.py（8123 端口）。
- 服务端源码无热重载，改 `apps/server` 后须重启 preview。
